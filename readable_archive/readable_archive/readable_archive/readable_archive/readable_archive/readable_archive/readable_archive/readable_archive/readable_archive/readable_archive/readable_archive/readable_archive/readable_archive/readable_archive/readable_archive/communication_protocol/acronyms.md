# Acronyms: Ultra-Dense Dictionary

## Op-Status
- `ACK` = Acknowledged
- `WIP` = Work In Progress
- `DONE` = Task Complete
- `BLOCK` = Blocker / TIC (Trouble in Code)
- `SITREP` = Situation Report
- `DEP` = Deployment
- `REF` = Reference
- `VAL` = Validation
- `HVT` = High Value Task

## Tech/Medical Hybrid
- `hx` = History (e.g., `hx: bug`)
- `p/w` = Presenting with (e.g., `p/w: 0.0 limit`)
- `r/o` = Rule out (Investigate)
- `bc` = Backward Compatibility
- `env` = Environment
- `cfg` = Configuration
- `ui` = User Interface
- `ux` = User Experience

## Operators
- `^` = Push / Update / Increase
- `v` = Pull / Decrease
- `+` = Add / Implement
- `-` = Remove / Delete
- `$` = Budget / Limit / Cost
- `@` = Destination / Target
- `=>` = Results in / Output
- `!` = Priority / Emergency
