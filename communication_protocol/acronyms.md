# Acronyms

- `ACK` = acknowledged
- `WIP` = work in progress
- `DONE` = finished
- `BLOCK` = blocked
- `FYI` = for your info
- `ETA` = estimate
- `ASAP` = as soon as possible
- `TBD` = to be decided
- `TBC` = to be clarified
- `N/A` = not applicable
- `Q?` = question
- `A:` = answer
- `PR` = pull request
- `PTAL` = please take a look
- `SGTM` = sounds good to me
- `NI` = need info
- `ND` = need decision
- `CFM` = confirm
