# Format

- `role: msg`
- `role: task: short`
- `role: note: short`
- `role: Q? <short>`
- `role: A: <short>`
- `role: BLOCK <reason>`
- `role: WIP`
- `role: DONE`
- `role: ACK`
- `role: FYI: <short>`

## Prefixes
- `DEV`, `QA`, `PM`, `UX`, `OPS`, `REVIEW`
- `PR#<id>` for pull request refs

## Use
- Use short tokens when phrases repeat.
- Use `doc: <summary> + link` for longer context.
