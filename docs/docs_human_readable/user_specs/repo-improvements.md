# Repo Improvements

This repo is a developer tool for managing a virtual AI team. The current improvements make the repository easier to use, better structured, and more explicit about its own improvement workflow.

## Acceptance criteria
- Root documentation clearly explains the repo purpose, onboarding path, and folder roles.
- Repo improvement requests are tracked in `user_requests/` and `tasks/`.
- Internal guidance for repo improvement work exists in `specs/repo-improvement-process.md`.
- User-facing repo improvement intentions are documented in `user_specs/repo-improvements.md`.
- The repository structure is consistent and ready for future documentation-driven improvements.
