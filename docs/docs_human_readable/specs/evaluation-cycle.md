# Evaluation Cycle

This document describes the quality and evaluation cycle for completed work.

## Purpose
- Ensure work is validated against success criteria.
- Review outcomes, artifacts, and process quality.
- Recommend improvements for the next iteration.

## Evaluation steps
1. Confirm success criteria from the request or product manager.
2. Review deliverables and artifacts against acceptance criteria.
3. Assess whether intermediate outputs were tracked and decisions documented.
4. Record findings in an evaluation note.
5. Capture recommendations for process improvement.
6. Archive the evaluation result in `archive/` with the completed task.

## Roles
- `Expert Product Manager` defines success criteria and clarifies requirements.
- `Validator` checks correctness and output quality.
- `State Tracker` records intermediate outputs and decisions.
- `State Manager` governs artifact tracking and state capture.
- `Evaluator` assesses outcomes and process effectiveness.

## Evaluation artifacts
- Use `templates/evaluation-template.md` for structured reviews.
- Store evaluation notes near the completed task or in `archive/`.
- Link relevant `user_requests/`, `tasks/`, `msgs/`, and `specs/` files.
