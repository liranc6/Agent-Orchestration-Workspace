# Workflow

Obsidian-style workflow notes for the team.

## Notes

- `[[process]]` - end-to-end flow from request to delivery

## Purpose

Describe how the team should move from user request through clarification, implementation, and delivery.

## Structure

- Start with mission clarity
- Resolve ambiguity before work begins
- Coordinate with developers before implementation
- Iterate with the user when questions remain
- Deliver only after review and validation
