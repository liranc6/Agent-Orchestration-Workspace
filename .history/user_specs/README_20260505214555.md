# User Specs

- Purpose: user-visible product specifications.
- Use this folder for agreed product definitions and feature docs.
- Users can read these files to understand what will be built.

## Structure
- One spec file per feature or product area.
- Keep content clear and direct.
- Do not use this folder for chat.

## Notes
- Publish stable, user-facing specs here.
- Use `user_requests/` for live request and clarification.
- Use `comunication_protocol/` and `workflow/` for process, not this folder.
