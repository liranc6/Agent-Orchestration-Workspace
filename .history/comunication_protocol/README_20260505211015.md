# Communication Protocol

This directory is structured like Obsidian notes. Use short files and links for easy team reference.

## Notes

- `[[format]]` - message shapes and syntax
- `[[acronyms]]` - approved tokens
- `[[common-phrases]]` - most repeated phrase patterns

## Core rules

- Text only. No calls.
- Minimal tokens. No extra words.
- No need for perfect grammar.
- Use short forms when a phrase repeats.

## Quick guide

- `role: task: short`
- `role: Q? <short>`
- `role: BLOCK <reason>`
- `role: DONE`
- `role: WIP`
- `role: ACK`
- `FYI: <short>`

## Use docs

- `doc: <short> + link`
- Keep docs separate from chat.
- Chat is for coordination only.

## Most common prefixes

- `DEV`, `QA`, `PM`, `UX`, `OPS`, `REVIEW`
- `PR#<id>` for pull requests

## Best practice

- If a note is needed, write it in a separate file and link it.
- If more than 2 lines are needed, use `doc:` and send the link.
- If unclear, send `Q?` with one line.
