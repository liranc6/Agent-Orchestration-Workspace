# Acronyms

Keep these tokens as the standard set.

- `ACK` = acknowledged / got it
- `WIP` = work in progress
- `DONE` = finished
- `BLOCK` = blocked / need unblock
- `FYI` = for your info
- `ETA` = estimate / timeline
- `ASAP` = as soon as possible
- `TBD` = to be decided
- `TBC` = to be clarified
- `N/A` = not applicable
- `Q?` = question / need clarification
- `A:` = answer
- `PR` = pull request
- `PTAL` = please take a look
- `SGTM` = sounds good to me
- `NI` = need info
- `ND` = need decision
- `CFM` = confirm

## Use

- Use acronyms only when they save tokens.
- Prefer the short form in commands that repeat.
- Avoid inventing one-off acronyms in team chat.
