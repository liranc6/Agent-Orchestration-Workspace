# Common phrases

Most repeated combinations for fast team chat.

## Repeated message patterns

- `DEV: task: fix <thing>`
- `DEV: WIP`
- `DEV: DONE`
- `DEV: BLOCK <reason>`
- `DEV: Q? <short>`
- `PM: task: <short>`
- `QA: TEST PASS`
- `QA: TEST FAIL`
- `REVIEW: PR#<id> ready`
- `REVIEW: PR#<id> changes needed`
- `OPS: deploy <env> <time>`
- `UX: note: <short>`
- `FYI: <short>`
- `A: ok`
- `A: ack`

## Most common short forms

- `need info` -> `NI`
- `need decision` -> `ND`
- `confirm` -> `CFM`
- `please take a look` -> `PTAL`
- `please merge` -> `PLM`
- `can you review` -> `CR`
- `test pass` -> `TP`
- `test fail` -> `TF`
- `work in progress` -> `WIP`
- `done` -> `DONE`
- `blocked` -> `BLOCK`
- `as soon as possible` -> `ASAP`
- `for your info` -> `FYI`
- `estimated` -> `ETA`

## Common reusable sentences

- `Q? need more info on <item>`
- `Q? CFM behavior for <item>`
- `DEV: BLOCK missing env creds`
- `DEV: DONE, ready for review`
- `REVIEW: PR#<id> PTAL`
- `REVIEW: PR#<id> SGTM`
- `QA: TEST PASS on <area>`
- `QA: TEST FAIL, bug <id>`
- `OPS: deploy prod ASAP`
- `PM: task: refine <feature>`

## Notes

- If a phrase repeats more than once in the same message, use the short form.
- Use exact tokens when possible to keep parsing and scanning fast.
