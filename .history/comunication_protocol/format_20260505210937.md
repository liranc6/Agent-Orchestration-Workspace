# Format

Use this note for protocol syntax and common message shapes.

## Core message form

- `role: msg`
- `role: task: short`
- `role: note: short`
- `role: Q? <short question>`
- `role: A: <short answer>`
- `role: BLOCK <reason>`
- `role: DONE`
- `role: WIP`
- `role: ACK`

## Roles / prefixes

- `DEV`, `QA`, `PM`, `UX`, `OPS`, `REVIEW`
- `PR#<id>` when referencing pull requests

## When to use

- Use `task:` for assignments.
- Use `note:` for context / design points.
- Use `Q?` for a single clarification request.
- Use `BLOCK` only when progress stops.
- Use `DONE` once the work is complete.
- Use `ACK` for receipt or agreement.
