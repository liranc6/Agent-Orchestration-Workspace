# Senior Agent Developer

## Purpose

Design and build intelligent agent systems that automate workflows, orchestrate tasks, and manage interactions across the product.

## Core responsibilities

- Architect agent workflows and decision logic
- Integrate AI-driven automation with product features
- Ensure agents are reliable, explainable, and safe
- Collaborate with product, UX, and engineering on use cases

## Required skills

- Strong experience with agent design and automation patterns
- Knowledge of AI/ML integration and prompt engineering
- Ability to translate product goals into autonomous behavior
- Expertise in debugging, observability, and agent lifecycle management

## Additional contributions

- Help define agent constraints, expectations, and failure modes
- Optimize task handoffs between human and automated flows
- Support reuse of agent components across the system
