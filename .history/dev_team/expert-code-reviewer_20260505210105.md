# Expert Code Reviewer

## Purpose

Ensure high code quality and consistent standards across the codebase. Catch defects early and guide the team toward better implementation choices.

## Core responsibilities

- Review pull requests for correctness, clarity, and maintainability
- Enforce architecture and style guidelines
- Provide constructive feedback and coaching
- Raise issues around design, testing, and security

## Required skills

- Strong fluency in the codebase and implementation patterns
- Ability to identify subtle bugs and architectural risks
- Clear communication and feedback delivery
- Experience with review workflows and automation

## Additional contributions

- Help define review checklists and quality gates
- Collaborate with QA and product on defect trends
- Foster a culture of continuous improvement
