# Junior Dev Programmer

## Purpose

Support feature implementation with guidance from senior engineers. Write clean, maintainable code and learn the project domain.

## Core responsibilities

- Implement user stories and bug fixes
- Follow established coding standards and architecture patterns
- Write unit tests and document code behavior
- Pair with senior developers and ask clarifying questions

## Required skills

- Basic proficiency in the project language and framework
- Understanding of version control (Git)
- Ability to read and follow technical specifications
- Willingness to learn and accept feedback

## Growth focus

- Improve code quality and architecture awareness
- Move from task execution to solution design
- Develop stronger estimation and communication skills
