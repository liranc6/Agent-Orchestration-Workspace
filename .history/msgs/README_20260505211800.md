# Messages

Team chat directory. Use it for text-only coordination and sub-channels.

## Structure

- Each user request or feature can have a thread/sub-channel.
- Use one folder or file per topic if needed.
- Keep messages short and token-efficient.

## Use

- Start a thread for each user request or issue.
- Add a note when the thread is new: `task: <short>`.
- Use `WIP`, `BLOCK`, `Q?`, `DONE`, `ACK` inside threads.
- Use sub-channels for parallel work, but keep each thread focused.

## Best practice

- `msgs/` is the active communication area.
- Link docs from `comunication_protocol` or `workflow` when needed.
- If the thread grows beyond 2 lines, move to a document and link it.
- Use `[[comunication_protocol/README]]` for rules and tokens.
