# User Requests

- Purpose: user request intake and team-user chat.
- Use this folder for all user requests and follow-up questions.
- Team responds here when user is involved.

## Structure
- One request directory per user request.
- Use the dir for message threads and sub-threads.
- Use `task: <short>` or `request: <short>`.
- Use `Q?`, `A:`, `ACK`, `BLOCK`.
- Keep user-facing messages short and clear.

## Notes
- `msgs/` is internal team chat only.
- If the team needs internal clarification, use `msgs/` in addition to `user_requests/`.
- Use `@role` or `@name` for direct attention in a request thread.
- When a request is agreed, move or copy final spec to `user_specs/`.
