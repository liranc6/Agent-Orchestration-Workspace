# Repo Improvements

This repo is designed as a developer tool for managing a virtual AI team. The current improvements focus on making the structure easier to use and more consistent.

## Changes made
- Corrected the folder name to `communication_protocol/` for messaging rules and shortcuts.
- Added a new `specs/` folder for technical documentation and implementation notes.
- Updated the root README and onboarding docs with clearer start steps and an improved folder overview.
- Updated internal docs and glossary references to use the corrected folder naming.

## Purpose
- Make the repo easier to navigate for new contributors.
- Reduce confusion by fixing inconsistent folder references.
- Separate user-facing specifications from internal technical documentation.
