# Common Phrases

- `DEV: task: fix <thing>`
- `DEV: WIP`
- `DEV: DONE`
- `DEV: BLOCK <reason>`
- `DEV: Q? <short>`
- `PM: task: <short>`
- `QA: TEST PASS`
- `QA: TEST FAIL`
- `REVIEW: PR#<id> ready`
- `REVIEW: PR#<id> changes needed`
- `OPS: deploy <env> <time>`
- `UX: note: <short>`
- `FYI: <short>`
- `A: ack`

## No redundancy
- `task: book` not `task: a book`
- `need info` not `I need more info`
- `confirm` not `please confirm`
- `done` not `finished successfully`
- `deploy prod` not `deploy to production environment`

## Short forms
- `need info` -> `NI`
- `need decision` -> `ND`
- `confirm` -> `CFM`
- `please take a look` -> `PTAL`
- `please merge` -> `PLM`
- `can you review` -> `CR`
- `test pass` -> `TP`
- `test fail` -> `TF`
- `work in progress` -> `WIP`
- `done` -> `DONE`
- `blocked` -> `BLOCK`
