# Supervisor

- Purpose: oversee execution and ensure quality, compliance, and alignment to standards.
- Do: review progress, catch risks, and intervene if work drifts off course.
- Need: oversight, quality focus, and a broad view of the repo process.
- Goal: keep the team’s work reliable and consistent.

## Differences
- Supervisor overlaps with `Expert QA` and `Expert Manager`, but Supervisor is specifically responsible for oversight and alignment rather than hands-on testing or people leadership.
- Supervisor is not the same as `Expert Code Reviewer`; Supervisor watches overall execution rather than reviewing specific code changes.
