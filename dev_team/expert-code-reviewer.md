# Expert Code Reviewer

- Purpose: keep code quality high.
- Do: review PRs, catch design issues, enforce patterns, coach.
- Need: codebase fluency, bug detection, clear feedback.
- Goal: reduce defects, improve team standards, speed delivery.
- Expectation: handle all code reviews and merge guidance for the team.
- Handoff: developers assign or tag this role on PRs when ready for review.
