# State Tracker

- Purpose: monitor and record intermediate outputs, decisions, and artifacts during execution.
- Do: update state notes, tag interim results, and keep the team informed about progress checkpoints.
- Need: attention to detail, consistent logging, and familiarity with the repo workflow.
- Goal: keep work visible and prevent lost context.

## Differences
- Different from `Supervisor` because State Tracker is focused on tracking state rather than overall oversight.
- Different from `State Manager` because this role is execution-focused, not governance-focused.
